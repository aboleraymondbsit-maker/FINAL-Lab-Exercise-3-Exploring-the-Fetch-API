LAB EXERCISE 3 – EXPLORING THE FETCH API

1. What are the main differences between XMLHttpRequest and Fetch API?

XMLHttpRequest uses an older approach to send HTTP requests and often requires callbacks and event handlers. Fetch API uses Promises, making it easier to handle asynchronous requests. Fetch also provides a simpler and cleaner syntax.

2. Why is the Fetch API considered more modern and readable?

The Fetch API is considered more modern because it uses Promises and supports async/await. Its syntax is shorter, cleaner, and easier to understand compared to XMLHttpRequest.

3. What is the purpose of the .then() and .catch() methods in Fetch?

The .then() method handles the successful completion of a Promise, such as receiving a response and converting it into JSON data.

The .catch() method handles errors that may happen during the request, such as network problems or other rejected Promises.

4. What happens when you send a POST request to the placeholder API?

When a POST request is sent to JSONPlaceholder, the API receives the submitted data and returns a simulated response containing the created post information and an ID.

For this activity, the returned post ID is 101. However, the data is not permanently saved on the server because JSONPlaceholder is a fake online REST API.
